
## ・アプリについて
シンプルなToDoアプリです。exeなのでデスクトップで動きます。pythonとflet習作。
## ・できること
タイトル,内容を入力でき削除、入力した内容の編集ができ必要最低限の機能がそろっています。
## ・操作方法
追加で一覧に追加されます。鉛筆マークを押すと修正ができます。ゴミ箱マークを押すと削除ができます。チェックボックスを押すと完了リストへ移動、外すと未完了になります。
## ・使用技術
Python 3.14.6とFlet　CLI 0.86.4　を使用
## ・起動方法
exeを起動していただくとそのまま使用できます。
## ・EXEの入手方法
このページのexeファイルをダウンロードしてください。
## ・現在の制限
締め切り日時、入れ子、ソートあたりは作ろうとしましたが日数がかかりすぎているため断念しています。もしほしいと言われたら実装を考えます。
## ・開発を通じて学んだこと
通常のターミナルで実行するpythonとfletはかなり違った。独特の考え方をなかなか適応できず完成までに時間がかった。
今もかなり遅いのでもっと考え方を柔軟に取り込んでいかないとflatと違うものや別言語を触ったときに習得が遅れるのですぐに考え方を取り込めるようにしたい。
